1. orbit.nvimとは                                    *orbit-introduction*

orbit.nvim は AI コーディングエージェントと協調しながら開発を行うための
Neovim プラグインです。

現在は Codex CLI を Terminal Buffer 上で利用するための Workspace を
提供しています。

将来的には以下の機能を提供することを目指しています。

* Context Sharing
* Session Management
* Multi-Agent Collaboration
* AGENTS.md Integration
* AI Agent Workflow Integration

==============================================================================
2. 動作要件                                          *orbit-requirements*

必要な環境:

* Neovim >= 0.12.0
* Codex CLI

対応状況:

Codex CLI      対応済み
Claude Code    対応予定
Gemini CLI     対応予定

==============================================================================
4. コマンド                                          *orbit-commands*

```
                                                *:OrbitStart*
```

:OrbitStart
AI エージェント Workspace を起動します。

```
                                              *:OrbitRelease*
```

:OrbitRelease
AI エージェント Workspace を停止します。

```
                                           *:OrbitSendBuffer*
```

:OrbitSendBuffer
現在編集中の Buffer を AI エージェントへ送信します。

```
                                        *:OrbitSendSelection*
```

:OrbitSendSelection
Visual Mode で選択中の範囲を AI エージェントへ送信します。

==============================================================================
5. 設定                                         *orbit-configuration*

基本設定:

>

require("orbit").setup({})
<

現在は追加設定項目はありません。
